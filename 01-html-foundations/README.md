## 💡 Key Concepts You'll Master

### 1. **HTML is a Markup Language, Not a Programming Language**

It doesn't "do" things. It **describes** things.

```html
<h1>This is a heading</h1>
<p>This is a paragraph</p>
```

You're just **labeling** content. That's it.

### 2. **Tags Come in Pairs (Mostly)**

```html
<opening>content</closing>
```

Some tags are self-closing:
```html
<img src="photo.jpg" />
<br />
```

### 3. **Nesting is Like Nesting Dolls**

```html
<div>
  <h1>
    <span>Nested!</span>
  </h1>
</div>
```

What opens last, closes first. Think of it like parentheses in math.

### 4. **Semantic HTML Means Using the Right Tag for the Job**

Don't use `<div>` for everything. Use:
- `<header>` for headers
- `<nav>` for navigation
- `<main>` for main content
- `<article>` for articles
- `<footer>` for footers

This makes your code **readable by humans and machines** (search engines, screen readers).

## 🎯 Success Criteria

You'll know you've mastered HTML when:
- You can look at a design and know which HTML elements to use
- You can structure a page without looking at documentation
- You understand why semantic HTML matters
- You can debug invalid HTML (unclosed tags, improper nesting)
