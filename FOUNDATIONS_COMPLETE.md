### ✅ Complete Working Examples
Every lesson includes full HTML/CSS/JavaScript code you can copy and run immediately.

Example from `03-arrays.md`:
```javascript
// Real-world shopping cart example
const cart = [
  { name: "Laptop", price: 999 },
  { name: "Mouse", price: 29 },
  { name: "Keyboard", price: 79 }
];

const total = cart.reduce((sum, item) => sum + item.price, 0);
console.log(`Total: $${total}`);  // Total: $1107
```
